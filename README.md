# Traffic Light

Ejercicio de interfaz React para representar un semáforo interactivo.

## Tecnologías

React, JavaScript y entorno Webpack del ejercicio.

## Instalación y uso

Clona el proyecto:

```bash
git clone https://github.com/jm181987/traffic-light.git
cd traffic-light
```

`npm install` y `npm run start`.

## Mantenimiento y seguridad

- Comprueba los scripts y las dependencias reales antes de desplegar.
- No publiques credenciales, claves ni datos privados.
- Documenta errores con pasos de reproducción y resultados esperados.
